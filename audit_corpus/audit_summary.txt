LIMITATIONS
pHash groups are candidates for visual similarity, not verified photographic sessions.
Distinct photographs may be grouped together; bursts, crops, or photographs from the same session may be missed.
A connected group may contain images whose pairwise distance exceeds the threshold (chaining).
EXIF dates are not validated; file modification dates are not used as capture dates.
An image containing multiple ponies retains the folder identity, without automatic verification of the subject.
The number of groups is not a measure of the number of independent photographic sessions.
Identical names in multiple folders must be resolved before creating splits.
For multi-frame GIF/TIFF files, only the first image is audited; the number of frames is reported.

No images were modified. No evaluation splits were created.
